# 情報源と検索クエリ例

| 情報源 | 分かること | 検索クエリ例 |
|---|---|---|
| 公式サイト（会社概要・事業紹介・製品・拠点・ニュース） | 基本情報、事業内容、拠点、工程や設備の写真・説明 | `"{社名}" 会社概要`、`"{社名}" 工場` |
| 国税庁 法人番号公表サイト | 正式社名・所在地・法人番号（同名企業の判別） | `"{社名}" 法人番号` |
| 都道府県・政令市が公表する「多量排出事業者の処理計画・実施状況報告」 | 産業廃棄物の種類別の排出量（前年度の排出量が1,000t以上、または特別管理産業廃棄物が50t以上の事業者が対象） | `"{社名}" 多量排出事業者 処理計画`、`{都道府県名} 多量排出事業者 処理計画 公表` |
| 環境報告書・CSR報告書・サステナビリティのページ | 廃棄物の排出量・リサイクル率・環境目標 | `"{社名}" 環境報告書`、`"{社名}" 廃棄物 リサイクル率` |
| 環境認証の登録情報（ISO14001、エコアクション21） | 環境管理の体制、認証の対象拠点 | `"{社名}" ISO14001`、`"{社名}" エコアクション21` |
| プレスリリース・ニュース | 工場の新設・増設・移転、設備更新、新製品 | `"{社名}" 新工場`、`"{社名}" 増設`、`"{社名}" プレスリリース` |
| 求人サイト・採用ページ | 工程や設備の具体的な内容（仕事内容の欄）、拠点の規模 | `"{社名}" 求人 仕事内容` |
| 業界団体・自治体の公開情報 | 業種、許認可、表彰 | `"{社名}" 組合`、`"{社名}" 認定` |

## 注意点

- 社名は必ず `"` で囲んで完全一致で検索する。同名企業がある場合は所在地や代表者名を加えて絞り込む。
- 有料の企業データベースの情報は取得しない。検索結果のスニペットに出ている範囲だけを使い、「スニペットより」と明記する。
- 多量排出事業者の情報は公表年度を必ず書く。
