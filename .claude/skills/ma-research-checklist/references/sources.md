# 非上場企業の情報源と検索クエリ例

非上場企業は有価証券報告書がないため、複数の情報源を組み合わせて調べる。

| 情報源 | 分かること | 検索クエリ例 |
|---|---|---|
| 公式サイト（会社概要・沿革・製品・ニュース） | 基本情報、事業内容、主要取引先、拠点 | `"{社名}" 会社概要` |
| 国税庁 法人番号公表サイト | 正式社名・所在地・法人番号（同名企業の判別） | `"{社名}" 法人番号` |
| 官報の決算公告 | 貸借対照表の要旨、当期純利益 | `"{社名}" 決算公告` |
| プレスリリース（PR TIMES など） | 新製品、提携、資金調達、受賞 | `"{社名}" プレスリリース` |
| ニュース・業界紙 | 業績の動向、事業展開、不祥事 | `"{社名}" ニュース`、`"{社名}" 業界名` |
| 求人サイト・採用ページ | 従業員数、注力分野、待遇、成長意欲 | `"{社名}" 採用`、`"{社名}" 求人` |
| 特許情報（J-PlatPat など） | 技術力、研究開発の分野 | `"{社名}" 特許` |
| 自治体・業界団体の公開情報 | 許認可、表彰、補助金の採択 | `"{社名}" 認定`、`"{社名}" 補助金 採択` |
| 行政処分・裁判の報道 | リスク情報 | `"{社名}" 行政処分`、`"{社名}" 訴訟` |

## 注意点

- 社名は必ず `"` で囲んで完全一致で検索する。同名企業がある場合は所在地や代表者名を加えて絞り込む。
- 企業データベース（帝国データバンク・東京商工リサーチなど）の有料情報は取得しない。検索結果のスニペットに出ている範囲のみ使い、「スニペットより」と明記する。
- 古い情報には年度を明記する（例：「従業員 120名（2023年時点）」）。
