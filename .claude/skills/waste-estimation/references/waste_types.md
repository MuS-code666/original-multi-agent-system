# 産業廃棄物の種類と区分

廃棄物処理法（施行令第2条）に基づく区分。推定した廃棄物は、必ずこの表の名称（法定区分）で書く。

## 1. 全業種共通の12種類（どの業種から出ても産業廃棄物）

| 法定区分 | 主な具体例 |
|---|---|
| 燃え殻 | 焼却炉の残灰、石炭がら |
| 汚泥 | 排水処理汚泥、建設汚泥、塗装かす、研磨くず、グリーストラップの汚泥 |
| 廃油 | 切削油、潤滑油、作動油、洗浄用の溶剤、廃塗料（油性）、廃インク、廃食用油 |
| 廃酸 | 廃硫酸・廃塩酸、酸洗い液、写真定着液 |
| 廃アルカリ | 廃ソーダ液、アルカリ洗浄液、写真現像液、金属せっけん液 |
| 廃プラスチック類 | 梱包フィルム・発泡スチロール、プラ製品くず、廃タイヤ（合成ゴム）、合成繊維くず |
| ゴムくず | 天然ゴムくず（合成ゴムは廃プラスチック類） |
| 金属くず | 鉄くず・非鉄くず、切削くず、スチール什器、空き缶・ドラム缶 |
| ガラスくず・コンクリートくず及び陶磁器くず | 板ガラス、空きびん、製品の製造過程で出るコンクリートくず、石膏ボード、レンガくず |
| 鉱さい | 鋳物砂、高炉・電気炉のスラグ |
| がれき類 | 工作物の新築・改築・除去に伴うコンクリート破片、アスファルト破片 |
| ばいじん | 集じん施設で集めたばいじん |

## 2. 業種が限定される7種類（対象業種以外から出ると事業系一般廃棄物）

| 法定区分 | 産業廃棄物になる業種 |
|---|---|
| 紙くず | 建設業（工作物の新築・改築・除去に伴うもの）、パルプ・紙・紙加工品製造業、新聞業、出版業、製本業、印刷物加工業 |
| 木くず | 建設業（同上）、木材・木製品製造業（家具製造業を含む）、パルプ製造業、輸入木材卸売業、物品賃貸業。**貨物の流通に使ったパレット（梱包用木材を含む）は全業種で産業廃棄物** |
| 繊維くず | 建設業（同上）、繊維工業（衣服その他の繊維製品製造業を除く） |
| 動植物性残さ | 食料品製造業、医薬品製造業、香料製造業（原料として使った動植物の固形状の不要物） |
| 動物系固形不要物 | と畜場、食鳥処理場 |
| 動物のふん尿 | 畜産農業 |
| 動物の死体 | 畜産農業 |

PCB が塗布・染み込んだ紙くず・木くず・繊維くずは、業種を問わず産業廃棄物。

## 3. 13号廃棄物
上記の産業廃棄物を処分するために処理したもので、上記のいずれにも該当しないもの（例：コンクリート固型化物）。

## 4. 特別管理産業廃棄物（爆発性・毒性・感染性があり、特別な処理が必要）

| 区分 | 主な具体例 |
|---|---|
| 廃油（引火性） | 揮発油類・灯油類・軽油類の廃油（引火点70℃未満）、引火性の廃溶剤 |
| 廃酸（腐食性） | pH2.0以下の廃酸 |
| 廃アルカリ（腐食性） | pH12.5以上の廃アルカリ |
| 感染性産業廃棄物 | 医療機関・研究機関から出る、血液の付着した注射針・ガーゼ・チューブなど |
| 特定有害産業廃棄物 | 廃PCB・PCB汚染物（古いトランス・コンデンサ・安定器）、廃水銀等、廃石綿等（飛散性アスベスト）、有害物質を基準以上含む燃え殻・ばいじん・汚泥・廃油（トリクロロエチレン等の廃溶剤）・廃酸・廃アルカリ・鉱さい |

## 5. 注意すべき区分

- **飲食店・小売店・オフィスの紙ごみ、生ごみ**：業種限定に当たらないため、事業系一般廃棄物（自治体の許可が必要。総合処理企業でも産業廃棄物の許可だけでは扱えない）。推定に含める場合は「事業系一般廃棄物（要確認）」とする。
- **廃食用油**：業種を問わず「廃油」として産業廃棄物。
- **蛍光管・水銀体温計など**：「水銀使用製品産業廃棄物」として、通常の産業廃棄物と分けて保管・処理する必要がある。
- **非飛散性の石綿含有建材**：特別管理産業廃棄物ではないが「石綿含有産業廃棄物」として分別が必要。
- **混合物**（廃 OA 機器、廃蛍光灯器具など）：構成する区分（廃プラスチック類・金属くず・ガラスくず など）を並べて書く。
