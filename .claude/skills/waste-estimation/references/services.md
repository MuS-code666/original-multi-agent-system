# 提案できるサービスと提案のルール

自社は、産業廃棄物であれば種類を問わず処理できる総合処理企業である。

## サービス一覧

| サービス | 内容 | 相手にとっての主な利点 |
|---|---|---|
| 一括受託（窓口の一本化） | 複数の種類の産業廃棄物を、収集運搬から処分まで1社で引き受ける | 委託先・契約・マニフェストの管理が1社分で済む |
| 定期回収 | 決まった頻度で拠点を回り、回収する | 保管場所の圧迫を防ぎ、回収の手配が不要になる |
| スポット回収 | 突発的に出る廃棄物を随時回収する | 設備更新や棚卸しのときにすぐ対応できる |
| 中間処理 | 破砕・焼却・中和・油水分離・脱水などで減量・無害化する | 処理の流れを1社で完結できる |
| リサイクル | 金属くずの資源化、廃プラスチック類の再生・燃料化（RPF）、木くずのチップ化、廃油の再生など | リサイクル率の向上、環境目標・環境報告書への反映 |
| 最終処分 | 中間処理後の残さを埋立処分する | 最後まで1社で責任を持てる |
| 特別管理産業廃棄物の処理 | 引火性廃油・廃酸・廃アルカリ・感染性廃棄物・PCB・石綿などを適正に処理する | 専門性の高い廃棄物も同じ窓口で相談できる |
| 一斉片付け・撤去 | 工場・倉庫・事務所の移転や閉鎖時に、まとめて分別・搬出する | 短期間で一度に片付く |
| 電子マニフェストの対応支援 | 電子マニフェストの導入や運用を支援する | 事務負担の軽減、報告書作成の手間の削減 |
| 廃棄物管理の相談 | 分別方法・保管方法・法令対応の相談に応じる | 担当者の負担と、法令違反の不安の軽減 |

## 提案のルール

- 推定した廃棄物の種類が多い企業には、まず**一括受託**を軸に提案する。
- 特別管理産業廃棄物が推定される場合は、その対応力を必ず提案に入れる（扱える処理業者が限られ、相手の困りごとになりやすいため）。
- 相手企業に環境認証や環境目標がある場合は、**リサイクル**による目標達成への貢献を提案に入れる。
- 最近の動き（新工場・移転・設備更新など）がある場合は、**スポット回収**や**一斉片付け**を提案に入れる。
- 提案は1社あたり**3つ程度**に絞り、優先順位を付ける。
- 価格・処理単価は書かない。現在の委託先を否定しない。相手企業の法令違反を断定しない。
