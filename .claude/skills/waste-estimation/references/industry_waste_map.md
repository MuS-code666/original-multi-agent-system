# 業種・工程と排出される廃棄物の対応表

調査メモで確認できた**工程・設備**から引く。業種名だけで推定する場合は、確度を「要ヒアリング」寄りにする。（特管）は特別管理産業廃棄物になりうるもの。

## 製造業

| 業種・工程 | 主な廃棄物（法定区分） |
|---|---|
| 金属加工：切削・研削 | 金属くず（切削くず）、廃油（切削油・研削油）、汚泥（研磨スラッジ） |
| 金属加工：プレス・板金・溶接 | 金属くず（端材）、廃油（プレス油）、鉱さい（溶接スラグ） |
| 表面処理：めっき・酸洗い・アルマイト | 廃酸・廃アルカリ（特管の可能性）、汚泥（排水処理汚泥。有害物質を含めば特管） |
| 塗装 | 廃油（廃塗料・廃シンナー。特管の可能性）、汚泥（塗装かす・水性塗料かす）、廃プラスチック類（マスキング材） |
| 洗浄・脱脂 | 廃油（洗浄溶剤。塩素系なら特管）、廃アルカリ（アルカリ洗浄液） |
| 鋳造 | 鉱さい（鋳物砂・スラグ）、ばいじん、金属くず |
| 樹脂成形 | 廃プラスチック類（ランナー・不良品・パージ材）、廃油（作動油） |
| 化学製品製造 | 廃酸・廃アルカリ・廃油（特管の可能性）、汚泥、廃プラスチック類（薬品容器） |
| 食料品製造 | 動植物性残さ（原料くず）、汚泥（排水処理汚泥）、廃油（食用油・機械油）、廃プラスチック類（包装材）、ガラスくず（びん） |
| 飲料製造 | 動植物性残さ（茶殻・果実かす）、汚泥、廃プラスチック類（PET・ラベル）、ガラスくず、金属くず（缶） |
| 印刷・製本 | 紙くず（損紙・裁断くず）、廃油（廃インク・洗浄溶剤）、廃アルカリ（現像液）、廃プラスチック類 |
| 木材・家具製造 | 木くず（端材・おがくず）、廃油（塗料）、汚泥（塗装かす）、金属くず |
| 電子部品・電気機器製造 | 廃プラスチック類、金属くず（非鉄を含む）、廃酸・廃アルカリ（エッチング液）、汚泥、ガラスくず |
| ボイラー・焼却炉を持つ工場 | 燃え殻、ばいじん |
| 排水処理設備を持つ工場 | 汚泥（脱水汚泥） |

## 建設業

| 工程 | 主な廃棄物（法定区分） |
|---|---|
| 解体工事 | がれき類、木くず、金属くず、廃プラスチック類、ガラスくず・コンクリートくず及び陶磁器くず、紙くず、繊維くず、廃石綿等（特管）・石綿含有産業廃棄物、PCB 含有の安定器（特管） |
| 新築工事 | 木くず（型枠・端材）、紙くず（梱包材）、廃プラスチック類、金属くず、ガラスくず・コンクリートくず及び陶磁器くず（石膏ボード端材） |
| 土木工事 | がれき類（アスファルト・コンクリート破片）、汚泥（建設汚泥） |
| 設備・内装工事 | 廃プラスチック類、金属くず、ガラスくず（蛍光管は水銀使用製品産業廃棄物） |

## 非製造業

| 業種 | 主な廃棄物（法定区分） |
|---|---|
| 自動車整備・販売 | 廃油（エンジンオイル）、廃アルカリ（不凍液）、廃プラスチック類（廃タイヤ・バンパー）、金属くず、廃酸（鉛蓄電池の電解液） |
| 運輸・物流・倉庫 | 木くず（パレット：全業種で産廃）、廃プラスチック類（ストレッチフィルム・PPバンド）、金属くず、廃油（車両整備） |
| 医療機関・介護施設 | 感染性産業廃棄物（特管）、廃プラスチック類（点滴容器）、廃酸・廃アルカリ（検査廃液・現像液）、水銀使用製品産業廃棄物 |
| 研究機関・試験所 | 廃酸・廃アルカリ・廃油（実験廃液。特管の可能性）、感染性産業廃棄物（特管） |
| 飲食・宿泊 | 廃油（廃食用油）、汚泥（グリーストラップ）、廃プラスチック類。生ごみ・紙ごみは事業系一般廃棄物 |
| 小売（スーパー・量販店） | 廃プラスチック類（梱包材）、金属くず、木くず（パレット）、廃油（総菜の食用油）。生ごみ・段ボールは事業系一般廃棄物（段ボールは有価物の場合あり） |
| 農業（畜産） | 動物のふん尿、動物の死体、廃プラスチック類（農業用ビニール） |

## 全拠点に共通する廃棄物（どの業種でも推定に加える）

| 発生のきっかけ | 主な廃棄物（法定区分） |
|---|---|
| 日常の事務・梱包 | 廃プラスチック類（梱包材・文具）、金属くず |
| 照明の交換 | 水銀使用製品産業廃棄物（蛍光管） |
| 什器・OA 機器の入れ替え | 金属くず・廃プラスチック類・ガラスくず（混合物） |
| 防災設備の更新 | 廃消火器（金属くず・汚泥など） |
| 移転・閉鎖・大規模な片付け | 上記すべて＋古いトランス・コンデンサ（PCB 含有の可能性：特管） |
