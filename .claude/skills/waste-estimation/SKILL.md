# 排出廃棄物の推定と提案ガイド

## ファイル構成

| ファイル | 内容 | 読むタイミング |
|---|---|---|
| `references/waste_types.md` | 産業廃棄物20種類（全業種共通12種類＋業種限定7種類＋13号廃棄物）、特別管理産業廃棄物、注意すべき区分 | 推定の前／レビュー時 |
| `references/industry_waste_map.md` | 業種・工程・設備と排出される廃棄物の対応表 | 推定中 |
| `references/services.md` | 総合処理企業として提案できるサービスと、提案のルール | 提案の作成時 |
| `templates/analysis.md` | 分析結果のひな形 | 書き出す時 |

## 手順

1. `references/waste_types.md` を読み、特に**業種限定の廃棄物**と**特別管理産業廃棄物**を確認する。
2. 調査メモの「業種」「拠点」「工程・設備・原材料」の記述ごとに、`references/industry_waste_map.md` で該当する廃棄物を洗い出す。全拠点に共通する廃棄物も忘れずに加える。
3. 洗い出した廃棄物ごとに、下記ルールで確度を付け、根拠を書く。
4. `references/services.md` から、廃棄物に対応するサービスと相手の利点を選ぶ。
5. 確度が「業種から推定」「要ヒアリング」の廃棄物について、確かめるためのヒアリング項目を作る。
6. `templates/analysis.md` のひな形に沿って書き出す。

## 確度のルール

| 確度 | 意味 | 根拠の書き方の例 |
|---|---|---|
| 公表情報あり | 相手企業の公表資料に、その廃棄物の排出が書かれている | `環境報告書2025に「廃プラスチック類 120t」と記載［調査メモ 出典3］` |
| 業種から推定 | 調査メモで確認できた工程・設備から、対応表に基づいて推定した | `調査メモで切削工程を確認 → 対応表「金属加工：切削」より廃油（切削油）` |
| 要ヒアリング | 業種一般では出る可能性があるが、相手企業での工程・設備が確認できていない | `塗装工程の有無が不明。工程があれば廃塗料（廃油・汚泥）が出る` |

- 1社あたりの推定は、**主要な廃棄物を5〜10種類**程度に絞る。
- 業種限定の廃棄物を推定する場合は、相手の業種が対象であることを根拠に書く。対象外の業種から出る場合は「事業系一般廃棄物（自社の対象外。要確認）」とする。
