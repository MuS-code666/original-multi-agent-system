# 虎屋 廃棄物の推定と提案

- 分析日：2026-10-18
- 元にした調査メモ：output/research/虎屋.md
- 対象拠点：株式会社虎屋 御殿場工場（静岡県御殿場市印野1581。羊羹・最中・水羊羹・季節の羊羹・煉菓子の製造、製餡）

## サマリー（3行）
- 推定した主な廃棄物：製餡・羊羹製造で出る動植物性残さ（不良品・餡くず・寒天くず・最中の皮くず）、包装・原材料袋の廃プラスチック類、品質検査の廃酸・廃アルカリ（特管の可能性）など9種類（公表情報あり0／業種から推定4／要ヒアリング5）。製餡で出る小豆の皮は有価売却されており、廃棄物の推定からは除く。
- 最も有望な提案：小豆の皮の有価売却は今のまま維持し、それ以外の動植物性残さ・包装材・検査廃液などを一括受託して窓口を一本化し、ISO14001の取り組みに合わせて動植物性残さと廃プラスチック類の再資源化を提案する。
- 訪問で最初に確かめること：小豆の皮以外の食品残さ（羊羹・餡の不良品、返品・期限切れ品、寒天・最中の皮くず）の量と現在の処理方法、および製餡排水の処理設備（汚泥の発生）の有無。

- 既存の取り組み（廃棄物の推定から除く）：製餡で出る**小豆の皮**は飼料として有価で売却され、畜産農家が利用している［調査メモ 出典2］。有価物は廃棄物に当たらないため、本分析の推定・提案の対象としない。訪問では評価すべき取り組みとして触れ、置き換えを提案しない。なお、京都工場では小豆の皮を近隣の処理施設に委託してバイオガス発電に利用している［調査メモ 出典2］（京都工場は今回の訪問拠点の対象外）。
- 事業系一般廃棄物（自社の対象外。要確認）：段ボール・紙箱・ラベル台紙などの紙ごみ（食料品製造業は紙くずが産業廃棄物になる業種に当たらない。段ボールは有価物の場合あり）、杉箱・竹皮など包装用の木材・植物素材の不良品や端材（貨物の流通に使ったパレットではなく、木くずの対象業種にも当たらないため）、社員食堂・事務所の生ごみ・紙ごみ。
- 燃え殻・ばいじん：ボイラーの燃料が都市ガスであるため［調査メモ 出典2］、ほとんど出ないと考えられ、推定から除いた。

## 3. ヒアリング項目
- 推定を確かめる質問：
  - 小豆の皮以外に、製造工程で出る食品残さ（羊羹・餡の不良品、釜や枠型の付着かす、寒天くず、最中の皮くず、桜葉・柚子などの原材料くず）はどのくらい出るか。現在はどのように処理しているか。（#1）
  - 店舗からの返品や賞味期限切れの製品を工場で回収して処分することはあるか。包装したままの製品を処分する場合、中身と包材の分別はどうしているか。（#1、#3）
  - 製餡や洗浄で出る排水は、工場内の排水処理設備で処理しているか。設備がある場合、脱水汚泥はどのくらい出ているか。（#2）
  - 社員食堂にグリーストラップはあるか。廃食用油と汚泥の回収はどうしているか。食堂の運営は委託か。（#2、#7）
  - 個包装フィルム・包材・原材料の袋の素材は何か（樹脂の種類、アルミ蒸着の有無など）。包材のロスはどのくらい出るか。（#3）
  - 水羊羹の容器は缶か樹脂か。原材料や資材を金属缶で受け入れているか。（#4）
  - 品質管理の理化学検査・機器分析で使う試薬の種類と、廃液の保管・処理の方法はどうしているか。微生物検査で使った培地・シャーレはどう処分しているか。（#5）
  - 生産ラインの洗浄・殺菌に使う薬品の種類は何か。洗浄の廃液は排水処理に流しているか、廃液として委託しているか。ボイラーで薬品を使っているか。（#6）
  - 煉り機・包装機などの潤滑油は何を使い、交換の頻度はどのくらいか。灯油を使っていたころの燃料タンクや配管は撤去済みか。（#7）
  - 原材料の納入や製品の出荷に木製パレットを使っているか。流通（箱詰め・発送）の拠点は御殿場工場内にあるか。（#8）
  - 工場の照明はLED化が済んでいるか。蛍光管・水銀灯の在庫や交換予定はあるか。1993年の改築以前からある受変電設備（トランス・コンデンサ）は残っているか。（#9、PCBの有無の確認）
- 現在の処理状況を知る質問（委託先の数、回収頻度、困りごとなど）：
  - 産業廃棄物の委託先は何社か。廃棄物の種類ごとに委託先が分かれているか。
  - 委託契約・マニフェストの管理は工場で行っているか、本社（生産支援部・事務管理部など）で行っているか。電子マニフェストを使っているか。
  - 食品残さの回収頻度は足りているか。夏場の臭気や保管場所で困っていることはあるか。
  - ISO14001の目標（廃棄物の削減・リサイクル率など）は設定しているか。廃棄物に関する目標で達成が難しいものはあるか。
  - 虎屋菓寮 御殿場店・とらや工房など近隣の店舗の廃棄物は、工場とまとめて管理しているか。
  - 今後、設備の更新・改修や照明のLED化の予定はあるか。

## 4. 訪問時の注意点
- 小豆の皮の有価売却（飼料として畜産農家が利用）は相手の環境への取り組みであり、評価する姿勢で触れる。置き換えや見直しを持ちかけない。
- 現在の委託先を否定しない。処理方法について法令違反を指摘・断定しない。区分が曖昧なもの（返品製品、杉箱・竹皮など）は「区分の確認をお手伝いできる」という言い方にとどめる。
- 価格・処理単価はその場で示さない。量と性状を聞いたうえで、見積もりは訪問後に行う。
- 紙ごみ・段ボール・生ごみ・杉箱などは事業系一般廃棄物に当たる可能性があり、自社の産業廃棄物の許可だけでは扱えない。依頼があれば、許可の範囲を確認してから回答する。
- 和菓子は贈答品としてのブランド価値が高いため、返品・不良品の処分では転売や流出を防ぐ確実な処分が関心事になりうる。この点は相手から話が出た場合に、処理の流れを説明する材料とする。
- とらや工房は株式会社虎玄の運営であり［調査メモ 出典1][出典3］、契約主体が虎屋と異なる。店舗まで話を広げる場合は契約先を分けて考える。
- 衛生管理の厳しい食品工場であるため、構内での回収時の動線・車両の衛生・作業時間帯への配慮ができることを伝える。
