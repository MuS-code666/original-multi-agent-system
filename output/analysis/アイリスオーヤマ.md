# アイリスオーヤマ 廃棄物の推定と提案

- 分析日：2026-10-18
- 元にした調査メモ：output/research/アイリスオーヤマ.md
- 対象拠点：アイリスオーヤマ株式会社 富士小山工場（静岡県駿東郡小山町桑木221-1）
- 前提：同工場の稼働内容として確認できたのは、飲料水（天然水・強炭酸水、PETボトル入り）の生産とPETボトルの内製（2021年時点）、物流倉庫（2025年11月時点の求人で確認）、社員食堂である。プラスチック製品の製造は2017年時点の記述しかなく、現在も続いているかは未確認のため、それに依存する推定はすべて「要ヒアリング」とした。廃棄物の排出量や種類を書いた公表資料は見つからなかったため、「公表情報あり」の推定はない。

## サマリー（3行）
- 推定した主な廃棄物：PETボトルの成形くず・不良ボトル・キャップ・ラベル（廃プラスチック類）、物流倉庫の梱包フィルム・PPバンド（廃プラスチック類）とパレット（木くず）、ラインやフォークリフトの作動油・潤滑油と食堂の廃食用油（廃油）、金属くず。洗浄・殺菌の薬品（廃酸・廃アルカリ。特管の可能性）と汚泥は要ヒアリングである（推定10件：業種から推定6件、要ヒアリング4件）。
- 最も有望な提案：製造ライン・物流倉庫・社員食堂から出る複数種類の産業廃棄物の**一括受託（定期回収込み）**。あわせて、単一素材で質の良いPETくずを中心とした**リサイクル**を提案する。
- 訪問で最初に確かめること：現在の稼働内容（プラスチック製品の製造が続いているか、飲料水のライン数、PETボトル内製の方式）と、処理委託の決定権が工場・本社（宮城県）のどちらにあるか。

- 事業系一般廃棄物（自社の対象外。要確認）：
  - 紙くず（段ボールケース・事務所の紙ごみ）：同社は紙くずが産業廃棄物になる業種（パルプ・紙・紙加工品製造業、印刷物加工業など）に当たらないため、事業系一般廃棄物となる。飲料水はケース単位で生産しており［調査メモ 出典3］、段ボールの破損品・端材が出る可能性があるが、ケースの材質は不明。段ボールは有価物として売却されている場合もある。
  - 社員食堂の生ごみ：事業系一般廃棄物。
- 推定に含めなかったもの：
  - 動植物性残さ：飲料水の原料は水と炭酸であり、茶殻・果実かすのような動植物の原料くずは出ないと考えられるため含めない。
  - PCB含有機器（特管）：建屋が1997年竣工であり、PCBを使った機器が設置されている可能性は低いと考えられるため含めない（念のため古い受変電設備の有無は確認してよい）。
  - 中身入りの不良品・破損品・返品（飲料水、出荷するアイリスグループ製品）：発生の有無や扱い（社内で処理するか、本社・物流部門が一括で扱うか）が不明のため、表には入れずヒアリング項目に回した。出る場合は、容器の廃プラスチック類や、製品を構成する区分（廃プラスチック類・金属くず・ガラスくず等の混合物）として扱う。

## 3. ヒアリング項目
- 推定を確かめる質問：
  - 現在も工場でプラスチック製品の製造を行っているか。行っている場合、品目・成形方式（射出成形・ブロー成形など）・使っている樹脂の種類、ランナーや不良品の発生量の目安と現在の扱い（社内で再利用しているか）（#7）
  - 飲料水のライン数は現在いくつか。2021年に計画された第2ラインは稼働しているか。今後の増設・更新や生産品目の変更の予定はあるか（#1、#6、提案3）
  - PETボトルの内製はどのような方式か（プリフォームを仕入れて成形しているか、樹脂から成形しているか）。成形くず・不良ボトル・キャップ・ラベルはどのくらい出て、どう分別しているか。有価物として売却しているものはあるか（#1）
  - 物流倉庫で出るストレッチフィルム・PPバンド・パレットの量と保管方法。パレットは木製かプラスチック製か、レンタルパレットか（#2、#3）
  - 成形機・充填機は油圧式か。作動油・潤滑油の交換頻度と廃油の保管方法。フォークリフトの整備は社内で行うか、リース会社・整備会社が行うか（#4）
  - 充填ラインやタンクの洗浄・殺菌にどのような薬品（酸性・アルカリ性の洗浄剤、殺菌剤）を使っているか。使った後の液は排水処理しているか、廃液として保管・委託しているか。使用期限切れの薬品が残っていないか（#8）
  - 排水処理設備はあるか。ある場合、脱水汚泥は出ているか（#9）
  - 社員食堂の運営は外部の会社か。廃食用油・グリーストラップ汚泥の排出事業者・委託契約はどちらの名義か（#5、#9）
  - 工場・倉庫の照明は蛍光管・水銀灯が残っているか、LED化の予定はあるか（#10）
  - 飲料水の不良品・破損品、出荷するグループ製品の破損品・返品は工場で廃棄することがあるか。ある場合の量と扱い
  - 富士小山工場はISO14001などの環境認証の対象になっているか。工場として廃棄物の削減・リサイクル率の目標はあるか（提案2）
- 現在の処理状況を知る質問（委託先の数、回収頻度、困りごとなど）：
  - 産業廃棄物の処理委託は、工場で決めているか、本社（宮城県）や本部で一括して決めているか。担当部署と決定までの流れ
  - 現在の委託先は何社か。廃棄物の種類ごとに委託先が分かれているか
  - 回収頻度は足りているか。繁忙期（夏場の飲料需要期など）に梱包材やパレットの保管場所が足りなくなることはないか
  - マニフェストは紙か電子か。管理や報告書の作成に手間を感じていないか
  - 処分に困っている廃棄物、現在の委託先では引き取ってもらえない廃棄物はないか
  - 設備の更新や倉庫の整理のときに、スポットで出る廃棄物の手配はどうしているか

## 4. 訪問時の注意点
- 調査メモの確度は「中」で、富士小山工場の現在の生産品目・ライン構成の最新情報は確認できていない。特にプラスチック製品の製造が続いているかは未確認のため、それを前提にした話し方をせず、まず現状を確かめてから提案を絞る。
- 処理委託の決定権が工場・本社のどちらにあるかが不明である。工場の担当者が決められない場合は、本社や他拠点（富士裾野工場など）を含めた一括の相談につなげられるかを確認する。
- 社員食堂は別会社が運営している可能性がある。食堂の廃棄物は、排出事業者がどちらかを確認してから提案する。
- 段ボール・事務所の紙ごみ・生ごみは事業系一般廃棄物であり、産業廃棄物の許可だけでは扱えない。相手から依頼があった場合は対象外であることを伝え、別途確認する。
- PETくずや段ボールは有価物として売却されている場合がある。現在の扱いを否定せず、リサイクルの選択肢として示す。
- 現在の委託先や処理方法を否定しない。法令違反を指摘・断定する言い方はしない。価格・処理単価はその場で示さず、量と性状を確認したうえで後日見積もりとする。
